# Галерея: избранное + папки (2026-10-16)

**Статус: реализовано.** Полный прогон после фичи — 1730 тестов, 0 падений. Новые тесты — `tests/gallery-folders-favorites.test.js` (8), обновлён `tests/tab-gallery-view.test.js` (пункты карточного меню).

## Задача

1. Добавить в галерее избранное: картинка закрепляется наверху.
2. Придумать удобную систему папок с двумя режимами — «Все картинки» и «Папки», где в папках можно сортировать как хочется.

## Дизайн

### Избранное (`favorite: boolean` на карточке)

- Поле проходит `ALLOWED`/`sanitizeGalleryCard` в `gallery-index.js`; дефолт — `false`.
- Закрепление — чистый хелпер `orderGalleryItems(items)` в `tab-gallery.js`: избранные наверх, внутри групп прежний порядок (новые сверху). Применяется к полному списку до фильтра по папке, поэтому «избранные сверху» работает и в ленте «Все», и внутри любой папки.
- Точки доступа: кнопка-звёздочка на карточке (hover-ряд), пункт «В избранное» карточного меню, кнопка в тулбаре просмотрщика (иконка и title следят за текущим слайдом через событие `change` PhotoSwipe, у картинок без карточки кнопка прячется), пункт контекстного меню просмотрщика.
- Визуал: золотая звезда в левом верхнем углу миниатюры (правый занят 💾), подсветка рамки карточки. Активная кнопка/звезда — `#f5b83d`.
- `toggleFavorite` не закрывает просмотрщик: действие безопасное и обратимое — контракт «закрывать только при успехе деструктивного» не задет; сетка под вьювером перерисовывается (карточка уезжает наверх).

### Папки (плоский список определений + `folders: string[]` на карточке)

Хранилище разделено по природе данных:

- **Определения папок** — маленький сателлитный файл `uris_gallery_folders.json` через `createFileStore` (`src/gallery-folders.js`, по образцу `template-file-store.js` и мета-сателлита папок референсов). Шардирование не нужно: коллекция не растёт вместе с галереей. Записи `{ id, name, color, order }` — форма референс-папок без дерева (палитра переиспользована из `refs-library`).
- **Принадлежность** — `folders: string[]` прямо на карточках шардированного индекса: мутируется одна карточка/шард, принадлежность переживает переименование папки и уезжает вместе с индексом.
- **Вид галереи** (режим `all|folders`, активный фильтр, сортировка папок) — device-local настройки `ur_image_studio.galleryViewPrefs`, как `folderPrefs` референсов: режим «Папки» на телефоне не включает режим «Папки» на десктопе и не ездит с бэкапом.
- Удаление папки — `deleteGalleryFolder` отстёгивает id от всех карточек одним `mutate` (`detachFolderFromCards`); картинки остаются в галерее.

### UX: два режима

Тулбар галереи: счётчик слева, сегмент-переключатель **«Все» / «Папки»** справа. Переключение сбрасывает фильтр (папочный фильтр вне режима «Папки» не имеет смысла).

Режим «Папки» добавляет под тулбаром горизонтальную ленту чипов (`.uris-gf-bar`):

- «Все» и «Без папки» — псевдочипы со счётчиками; затем пользовательские папки (цветная точка + имя + счётчик), порядок — по prefs;
- «＋» — создать папку (модальный ввод);
- «⋯» — сортировка чипов: свой порядок / по имени / по количеству (переиспользованы чистые `orderSidebarFolders`/режимы из `folder-picker.js`);
- клик по чипу — фильтр сетки; пустая папка и «Без папки» имеют свои тексты пустого состояния;
- ПКМ / долгий тап по чипу папки — меню: переименовать, сменить цвет (цикл по палитре), удалить (с подтверждением; активный фильтр падает обратно на «Все»).

Назначение картинок — через **«Папки…»** в карточном меню и в контекстном меню просмотрщика: `openFolderSheet` в multi-режиме (тот же лист, что у референсов): мультивыбор, переключение применяется сразу (autosave-семантика), создание папки по запросу без точного совпадения. Одна картинка может лежать в нескольких папках.

## Намеренно не делаем (v1)

- Дерево папок и drag&drop карточек: лента чипов + мультилист закрывают раскладку при меньшей сложности; дерево осталось в референсах, где оно выросло из 50+ папок.
- Бэкап: галерея (`uris_gallery_*`) принципиально не переносится экспортом — папки галереи следуют за ней.
- Закрепление папок (pinned), как у референсов: сортировки пока достаточно; prefs-нормализатор расширяется без миграций.

## Контракты

- `gallery-index.js`: `ALLOWED` + `favorite`/`folders`; `detachFolderFromCards(folderId)`.
- `gallery-folders.js`: CRUD (`listGalleryFolders/createGalleryFolder/updateGalleryFolder/deleteGalleryFolder`), `getGalleryViewPrefs/saveGalleryViewPrefs`, `GALLERY_FOLDERS_FILE_NAME`.
- `gallery-actions.js`: `toggleFavorite(item, root)` (возвращает новое состояние), `assignGalleryFolders(item, root)`.
- `tab-gallery.js`: `orderGalleryItems`, `filterGalleryByFolder`, `galleryFolderCounts` — экспортированы для тестов.
