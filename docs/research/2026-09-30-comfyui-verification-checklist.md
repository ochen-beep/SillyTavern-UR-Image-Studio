# Инструкция по проверке интеграции URIS ↔ ComfyUI (для агента/нейросети)

> Дата: 2026-09-30. Составлена после реализации контракта `comfyui` в расширении UR Image Studio. Это инструкция по живой проверке — код написан, автотесты зелёные (1447/1447), живого прогона с реальным ComfyUI ещё не было.

## Контекст (обязательно прочитай)

- **UR Image Studio (URIS)** — расширение SillyTavern для генерации картинок. Живёт в `D:\SillyTavern QA\data\default-user\extensions\UR Image Studio` (это одновременно и рабочая копия расширения, и git-репозиторий). SillyTavern 1.19.0 запускается локально; расширение уже установлено и включено.
- Только что в URIS добавлен новый провайдер — **локальный ComfyUI** (контракт `comfyui`). Механика: URIS берёт workflow в формате «Export (API)» (встроенный дефолт, если поле пустое), подставляет в него `%model%`, `%prompt%`, `%seed%`, `%width%`, `%height%`, отправляет `POST /prompt`, поллит `GET /history/{id}`, забирает картинку через `GET /view`. Референсы: `POST /upload/image` (multipart) → раскладка в ноды `LoadImage` по возрастанию ID нод.
- Твоя задача — прогнать проверочные сценарии на машине, где стоит ComfyUI, и вернуть структурированный отчёт. **Код не менять.** Если что-то не работает — зафиксировать симптом, а не чинить.

## Шаг 0. Подготовка ComfyUI

1. Найди, как на этой машине запускается ComfyUI (папка установки, существующий .bat/ярлык). Типовые варианты:
   - Portable: `cd ComfyUI_windows_portable` затем `.\python_embeded\python.exe main.py --enable-cors-header "*"`
   - Git/venv: `python main.py --enable-cors-header "*"`
2. **Флаг `--enable-cors-header "*"` обязателен** для прямого доступа из браузера: без него встроенный origin-middleware ComfyUI молча режет запросы с чужим Origin (даже с той же машины, другой порт = другой origin). Это причина №1 всех «не работает».
3. Запусти сервер и проверь доступность:
   - `curl http://127.0.0.1:8188/system_stats` → должен вернуть JSON с `comfyui_version` (запиши версию в отчёт);
   - проверь CORS: `curl -i -X OPTIONS http://127.0.0.1:8188/system_stats -H "Origin: http://localhost:8000" -H "Access-Control-Request-Method: GET"` → в ответе должен быть заголовок `Access-Control-Allow-Origin`;
   - `curl http://127.0.0.1:8188/models/checkpoints` → список чекпойнтов. **Выбери один и запиши точное имя файла** (например `v1-5-pruned-emaonly.safetensors`) — оно пойдёт в поле «Модель» URIS. Если список пуст — положи любой SD-чекпойнт в `models/checkpoints/` и перезапусти ComfyUI.
4. Убедись, что в браузере на этой машине открывается `http://127.0.0.1:8188` (UI ComfyUI загружается).

## Шаг 1. Подготовка SillyTavern + URIS

1. Открой SillyTavern в браузере (обычно `http://localhost:8000`) и сделай **жёсткую перезагрузку страницы (Ctrl+F5)** — файлы расширения обновились на диске, старые модули закэшированы.
2. Открой плавающую кнопку UR Image Studio → вкладка **API** → добавь новое подключение (карточка «Серверное подключение»):
   - **Имя**: `ComfyUI local`
   - **Адрес**: `http://127.0.0.1:8188`
   - **Ключ**: оставить пустым
   - **Расширенные → Протокол**: выбрать `ComfyUI (локальный workflow)`
   - В карточке появится поле **«Workflow (API-формат)»** — оставить **пустым** (это тест встроенного дефолта).
   - Вернуться к основным полям: **Модель** → выбрать «— ввести ID вручную —» и ввести точное имя чекпойнта из шага 0.3.
   - **Расширенные → Таймаут**: для слабой машины поставь 600 (сек), для быстрой достаточно 300.
3. Дождись автосохранения. Статус-точка карточки станет **жёлтой («Не проверено»)** — это норма: кнопка «Проверить» для ComfyUI не работает (модель вводится вручную), это задокументированное ограничение, а не баг.
4. Активируй подключение кнопкой «Сделать активным».

## Шаг 2. Тесты (по порядку, каждый — с ожидаемым результатом)

**Т1. txt2img на встроенном workflow.** Вкладка Generate → режим «вручную» (только твой промпт) → простой промпт (`a cozy cabin in the woods, warm light`) → «Стороны» = `16:9` → Запустить.
- Ожидание: через несколько секунд–минуты в ленте появится результат, картинка — во вкладке Gallery; в ComfyUI в папке `output/` появится файл `uris_*.png`.
- Проверка геометрии: у карточки в галерее должны быть размеры 1024×576 (16:9 маппится ровно в это).
- Ожидаемый признак в UI: никаких warning-ов (сид подставлен, аспект точный).

**Т2. Референсы (встроенный img2img).** Вкладка References → загрузи одну картинку-референсу → в Generate при запуске референс должен прикладываться (режим отправки «Всегда» на подключении, или прицепи вручную) → генерация с промптом «same character, new pose».
- Ожидание: генерация проходит, в ComfyUI в `input/` появится `uris_<id>_ref1.png`, результат визуально связан с референсой (denoise 0.65).
- Если упадёт с ошибкой про multipart/CORS — проверь, что флаг `--enable-cors-header "*"` действительно передан (шаг 0.2) и ComfyUI перезапущен с ним.

**Т3. Свой workflow.** В ComfyUI собери или открой любой простой txt2img-граф → меню Workflow → **«Export (API)»** (не обычный Save!) → содержимое JSON вставь в поле «Workflow (API-формат)» карточки подключения. В экспортированном графе подставь плейсхолдеры в текст позитивного промпта: замени значение `text` у CLIPTextEncode на `%prompt%`, у KSampler значение `seed` на `%seed%`, у чекпойнт-лоадера `ckpt_name` на `%model%` → генерация.
- Ожидание: работает, картинка в галерее; промпт из URIS попадает в граф.

**Т4. Отмена.** Запусти генерацию (шаги по 1%) и нажми «Остановить» в URIS.
- Ожидание: ожидание в URIS прекращается; в ComfyUI очередь освобождается (текущая задача прерывается). Проверь `curl http://127.0.0.1:8188/queue` → пустые `queue_running`/`queue_pending`.
- На старых версиях ComfyUI `/interrupt` глобальный — если в очереди была чужая задача, прервётся и она (известное поведение, не баг).

**Т5. Ошибки — читаемый текст.** По очереди:
- В поле «Модель» введи несуществующее имя чекпойнта → генерация → ожидание: ошибка `COMFY_PROMPT_REJECTED`, в тексте видно имя ноды и причину (например `CheckpointLoaderSimple [...] Value not in list`). Верни правильное имя.
- В поле workflow вставь UI-формат (обычный Save из ComfyUI) → ожидание: `COMFY_NO_OUTPUT` с подсказкой про «Export (API)».
- Вставь валидный API-JSON без `%prompt%` → ожидание: `COMFY_PROMPT_MISSING`.

**Т6 (опционально). Дорога через прокси ST.** Перезапусти ComfyUI **без** CORS-флага. В карточке подключения: Расширенные → Доставка = «Через CORS-прокси ST». В `config.yaml` SillyTavern должно быть `enableCorsProxy: true` (если выключено — включи и перезапусти ST).
- txt2img: ожидание — работает (JSON POST/GET переносятся прокси, бинарный GET /view прокси стримит).
- Референсы: ожидание — **честная ошибка** про multipart/CORS (прокси не переносит FormData) — это задокументированное ограничение, не баг.
- После теста верни флаг и перезапусти ComfyUI.

## Трактовка типовых сбоев

| Симптом | Причина | Действие |
|---|---|---|
| «Failed to fetch» / CORS / HTTP 403 | Нет `--enable-cors-header "*"` или ComfyUI не перезапущен с ним | Шаг 0.2, перезапустить сервер |
| Прямая не работает, прокси работает | То же самое | Включить «Через прокси ST» и жить так, или починить флаг |
| ST открыт по https или по LAN-IP (не localhost), прямая не работает даже с флагом | Chrome Private Network Access блокирует запросы к 127.0.0.1 с «менее приватного» origin | Открой ST на `http://localhost:8000` и повтори |
| Таймаут (`COMFY_JOB_TIMEOUT`) | Медленная модель или очередь сервера занята чужой задачей | Поднять «Таймаут», освободить очередь ComfyUI |
| `COMFY_PROMPT_REJECTED` | Отсутствуют кастомные ноды графа на сервере / неверное значение combo | Читай имя ноды в тексте ошибки, ставь ноды или упрощай граф |
| Картинка повторяется при каждом запуске | В кастомном workflow нет `%seed%` | Замени seed в KSampler на `%seed%` (в URIS будет warning «Seed») |
| Референсы не встали в нужную ноду | Несколько LoadImage: порядок — по возрастанию ID нод | Пересоздай ноды в нужном порядке или используй одну LoadImage |

## Границы задачи

- Код расширения не менять; автотесты (`npm test` в папке расширения) не трогать — если хочешь убедиться в базовой целостности, прогони и запиши результат.
