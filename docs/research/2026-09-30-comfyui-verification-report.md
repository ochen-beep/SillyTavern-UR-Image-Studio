## 2. Расхождения «чеклист vs факт» (править чеклист/доки, не код)

- **Д-1. «Референсы: режим Всегда отправлять» не прицепляет референсы сам.** Выбор в пуле на вкладке «Референсы» (`uris-pool-tile-selected`) + режим «always» на подключении НЕ добавляют референсы в генерацию: строка «Выбрано для генерации» осталась 0/…, задача ушла как txt2img. Референсы для конкретной генерации прицепляются на вкладке «Генерация» (стрип «Выбрано для генерации», кнопка «+» → пикер) либо через whitelist чата/привязку. Сценарий Т2 в чеклисте («загрузи референсу на вкладке References → запусти») в таком виде не работает.
- **Д-2. «В ленте появится результат» для режима «Вручную» неверно.** По USER_GUIDE картинки складываются в галерею, инлайн-превью — только под постами-источниками (маркеры/камера). В ручном режиме нового поста в чате нет. Ожидание Т1 переформулировать: «результат в галерее + уведомление».
- **Д-3. Порты.** ST в этой установке на 8002, не 8000. Бэкенд ComfyUI Desktop (Electron) живёт на 8001 и НЕ принимает `--enable-cors-header` от десктопа; для URIS бэкенд надо поднимать вручную на 8188 (см. раздел 3).
- **Д-4. Имя файла референсы** — `uris_<id>_ref1.jpg`, не `.png` (в URIS_Refs референсы лежат webp, на upload уходят jpg).
- **Д-5. Версия ST** в окружении 1.18.0, чеклист писал 1.19.0.

## 3. Грабли окружения (важно для повторного прогона)

1. **ComfyUI Desktop не прокидывает `--enable-cors-header`** в свой бэкенд и занимает порт 8001. Рабочая схема: остановить десктопный бэкенд и запустить `main.py` из `.venv` установки вручную с флагом CORS на 8188. Проверять занятость порта: `netstat -ano | grep 8188`.
2. **`download_model_base` в extra_model_paths.yaml игнорируется ComfyUI 0.38** (парсер `utils/extra_config.py` трактует его как имя папки моделей). Десктопный yaml из-за этого не даёт моделей вручную поднятому бэкенду. Лечится явными ключами папок (`checkpoints:`, `diffusion_models:`, `vae:` и т.д.) в своём yaml — рабочий пример: `D:\tmp\uris_test_extra_models.yaml`.
3. При ручном запуске бэкенда без `--input-directory/--output-directory` папки input/output берутся из установки, а не из общей `E:\comfyUI1` — артефакты тестов тогда надо искать там.
4. Для браузер-автоматизации: часть контролов окна URIS (кнопки свёрнутых карточек) не проходит Playwright-actionability (hidden) — кликать через `evaluate(el.click())`. Это особенность автоматизации, не баг расширения.

## 4. Что можно доработать (предложения, не баги)

1. **Режим «Всегда отправлять» референсы**: семантика читается как «приложить референсы автоматически», а по факту влияет только на политику уже выбранных. Добавить явный механизм авто-прицепления (например, «всегда слать whitelist чата» или «повторять последний набор») либо подсказку в UI строки «Референсы» на карточке подключения.
2. **Персистентность стрипа референсов на «Генерации»**: выбранные референсы переживают следующие генерации и молча меняют граф (txt2img→img2img; с кастомным графом без LoadImage — ошибка). Показывать счётчик референсов рядом с кнопкой «Сгенерировать» и в ленте очереди, чтобы смена графа не была сюрпризом (в прогоне Т3 это стоило одного лишнего запуска).
3. **COMFY_PROMPT_REJECTED**: в тексте ошибки давать `class_type` ноды, а не только внутренний номер `node [4]` — сервер в `node_errors` это отдаёт, читателю было бы понятнее.
4. **Лайтбокс галереи**: метаданные (размер, seed, промпт) не видны в просмотрщике; размеры есть только в атрибутах карточки. Приятно иметь, не критично.
5. Чеклист: поправить ожидания Т1/Т2 и порты (раздел 2).
