## Что проверено и прошло

- **Загрузка**: расширение поднялось, ошибок инициализации не видно; `globalThis.URIS` опубликован (мост работает). При повторном открытии — честное предупреждение «уже открыт в другой вкладке» (cross-tab).
- **Вкладки**: все 8 (API/Референсы/Генерация/Галерея/Шаблоны/Мост/Медиа/Настройки) переключаются.
- **API**: «Проверить» на активном коннекте обновила строку фактов («39 image-моделей из 175 · проверено только что»); у других коннектов видны факты доставки (через прокси / без прокси, референсы подтверждены).
- **Шаг 1**: «Построить промпт» собрал промпт из чата (текстовый профиль google/gemini-3.8-flash).
- **Шаг 2**: картинка сгенерирована (gemini-3.1-flash-image через прокси ST), появилась в галерее, тост «Картинка сгенерирована».
- **Ошибка провайдера**: на коннекте elysium (chat-completions) модель google/nano-banana-2.1 дала HTTP 422 — тост с человекочитаемым текстом, задача в ленте с кнопкой «Повторить». Расширение отработало корректно (это конфиг стенда, не баг).
- **Очередь**: бейдж QUEUE считает живые задачи; лента со статусами («выполняется»/«готово»); «Остановить очередь» и кнопка «Остановить» рядом с «Сгенерировать» появляются во время работы; «Очистить завершённые» на месте.
- **Лайтбокс**: PhotoSwipe открывается из карточки; кнопки: полноэкранный, закрыть, избранное, копировать текст, обрезать (в новую карточку), сохранить как референс, перегенерировать, удалить, навигация ←/→.
- **Избранное**: звезда с карточки переключает состояние (`uris-card-fav`, «Убрать из избранного»), переживает перезагрузку страницы.
- **Инлайн**: пост `[[img: …]]` → заглушка «📷 Нарисовать» (ручной режим) → клик → генерация → компакт-чип «📷 Картинка» (компакт-режим) → клик раскрывает полную картинку. Чип пережил перезагрузку страницы.
- **Персистентность**: после перезагрузки — закрытое состояние окна, галерея (4 картинки), избранное, инлайн-чип. После перезапуска СЕРВЕРА — папка галереи на месте.
- **Папки галереи**: режим «Папки», чипы «Все/Без папки/папка» со счётчиками; создание через ＋ (ST-модалка); назначение через меню карточки «Папки…» (мульти-выбор, ✓); фильтр по чипу; ПКМ по чипу → «Переименовать / Сменить цвет / Удалить»; удаление с честным подтверждением «картинки останутся» — карточки целы.
- **«Вставить шаблон»**: инструкция шаблона вставлена в редактор промпта (3503 → 8192 символа), макросы {{char}}/{{user}} подставлены (в тексте не остались).
- **Настройки**: «Экспорт данных», «Диагностика», «Сетевой дамп» — все отдают файл на скачивание.

## Замечания / потенциальные дефекты

1. **[minor, проверить] Обновление ленты папок после создания.** Папка «Тестовая папка» записалась в store (`uris_gallery_folders.json`) сразу, но чип в тулбаре появился только после переключения вкладки (принудительного перерендера). Возможно, `render(root)` после `createGalleryFolder` отрабатывает до флаша записи или чип-лист берёт кэш. Кейс 10.3 пометить «требует ручной перепроверки».
2. **[doc/expected] «Остановить» при доставке через прокси.** 4K-генерация завершилась и попала в галерею после нажатия «Остановить» — соответствует документации («прокси отмену не передаёт»), но в ленте задача отмечена «готово», а не «отменена, запрос оплачен». Подумать о явном статусе.
3. **[info] Дедуп повторного клика «Сгенерировать» с неизменным промптом.** Три быстрых клика поставили одну задачу; после изменения промпта — следующую. Выглядит как намеренная защита от дублей; в плане кейс 6.1 уточнить (разные промпты → несколько задач).
4. **[env] Стекинг ST-попапов.** Повторные клики ＋ открывают несколько модалок «Имя папки» одновременно (4 шт.). Это поведение `callGenericPopup` ST, не расширения; на живом UI маловероятно.

## Не покрыто прогоном (нужен ручной проход)

- Загрузка референсов пачкой и кроп при загрузке (IAB не умеет file chooser).
- Мобильный профиль (жесты, долгий тап).
- Таймаут подключения на медленной модели; «Разведка перед первым POST» на новом коннекте; цепочка диалектов редактирования (multipart→JSON→img2img).
- Импорт данных (нужен чистый профиль).
- Два окна ST одновременно (cross-tab конфликты галереи).
- Регрессия 9.3 (readonly-режим шаблонов).
