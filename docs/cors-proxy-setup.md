# Гайд: CORS и прокси SillyTavern для UR Image Studio

> Для владельца и пользователей. Уровень: `config.yaml` SillyTavern, ~5 минут. Дата: 2026-10-14.

Как устроена доставка: расширение ходит к провайдерам **прямо из браузера** и всегда сначала пробует прямое соединение. Часть провайдеров разрешает такие запросы (OpenRouter, Gemini, Pollinations) — им прокси не нужен вообще. Другие не отдают CORS-заголовки (например, `api.cloudflare.com` или ComfyUI без флага `--enable-cors-header`) — браузер такие запросы блокирует, и тут помогает **встроенный прокси SillyTavern**: тот же запрос уходит через ваш собственный ST-сервер, который делает запрос уже не из браузера, и ограничения CORS на него не действуют.

Сторонние серверы-посредники не используются ни в каком режиме: прокси ровно один — штатный, локальный, из коробки SillyTavern.

## Как включить

1. Откройте `config.yaml` в корне SillyTavern.
2. Найдите строку `enableCorsProxy: false` и поставьте `true`.
3. Перезапустите SillyTavern.

Это всё. Режим доставки «Авто» разберётся сам: провайдеры с CORS продолжат ходить напрямую, а без CORS — через прокси. Включённый прокси подхватывается без перезагрузки страницы (до ~15 секунд после рестарта ST).

## Чего прокси не делает

- **Не уводит ваши ключи.** Ключи подключения URIS живут в браузере (localforage), в `settings.json`, бэкапы и дампы не попадают и прикрепляются только к запросам вашего же подключения — к тому провайдеру, к которому вы сами обратились.
- **Никуда не сообщает о вас.** Через `/proxy/` проходит только то, что вы запросили из UI. Логи запросов на вашей стороне — сетевой дамп URIS, и тот пишет только метаданные.

## Гигиена SillyTavern (одна настройка на всю инсталляцию)

Включённый прокси — общий релей для всех, у кого есть доступ к вашему ST. В локальной установке «только этот компьютер» об этом можно не думать. Если же ST доступен с других устройств (телефон, второй ПК) — стоит потратить две минуты в том же `config.yaml`:

| Настройка | Зачем |
|---|---|
| `cors.origin`: список адресов вместо `"*"` | Перечислите, откуда сами открываете ST (`http://127.0.0.1:<порт>`, `http://<IP-ПК>:<порт>`, …). Посторонние сайты перестанут читать ответы вашего сервера — включая `/proxy/`. Для вас ничего не меняется: свой UI открывается с этих же адресов. |
| `whitelist`: конкретные устройства | Вместо всей домашней подсети вида `192.168.1.0/24` — только те IP, которым реально нужен доступ. |
| `allowKeysExposure: false` | Запрещает отдавать ключи ST-подключений в открытом виде через API. URIS этот флаг не требует — можно смело выключать. |
| `basicAuthMode: true` | Обязателен, если выставляете ST за пределы домашней сети (проброс порта, туннель). |

После правок `config.yaml` SillyTavern перезапускаем.
