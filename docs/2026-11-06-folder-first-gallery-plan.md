# План: folder-first галерея (2026-11-06)

## Проблема

Галерея URIS держит источник истины в JSON-индексе карточек, а нативная галерея
ST — в файловой системе (`user/images/<персонаж>`). Рассинхрон неизбежен:
потеря индекса → пустая галерея при полном диске; карточка с чужим/старым
chatId → невидима; файл удалён, карточка осталась → битое превью;
переименование чата → все его карточки «исчезают». Инцидент 2026-11-05
(потеря индекса при ручной правке шардов) показал цену вопроса.

## Решение

Папка персонажа первична, карточки — сайдкар метаданных по `imagePath`.

1. Вид «Галерея» читает список файлов папки текущего персонажа
   (`listNativeImages`, уже есть) и джойнит карточки по `imagePath`.
   Файл есть → виден всегда; карточка есть → промпт/seed/папки/избранное.
2. Скоуп: чипы «Всё» (дефолт) / «Этот чат» (карточки с `provenance.chatId`).
   Студия → своя папка (STUDIO_IMAGE_FOLDER). Групповые чаты — роадмап №28.
3. Действия над бескарточным элементом (избранное, папка, миниатюра) создают
   минимальную карточку лениво. Удаление файла — `/api/images/delete` +
   удаление карточки, если была.
4. Битые превью исчезают как класс: нет файла → нет элемента. reconcile
   остаётся для пометок `missing`/сирот в «Уходе за данными», но перестаёт
   быть несущим.
5. GC при удалении чата — только чистка индекса (метаданные), файлы не
   трогаются (как и сейчас; совместимо с архитектурой ST).

## Data Maid после рефакторинга

Класс «индекс врёт» исчезает: Data Maid показывает ровно то, что видно в
галерее. Риск удаления самих файлов остаётся (кроме вставленных в посты) —
это прозрачное пользовательское решение, а не скрытое состояние.

## Референсы (отдельно, из wip-ветки)

`user/files/uris_ref_*` + реестр в `extension_settings.character_attachments`
(псевдо-ключ «URIS Storage», не рендерится в Data Bank UI). Data Maid считает
их известными. Не раздувает карточки персонажей и чаты — реестр живёт в
settings.json (~60 Б на файл). Подпапочный трюк (`user/files/uris/`) не
используем: зависит от квази-поведения плоского сканера.

## Затронутые модули

- `src/storage.js` — getGallery: folder-first + джойн карточек.
- `src/ui/tab-gallery.js` — чипы скоупа, рендер бескарточных элементов.
- `src/gallery-index.js` — reconcile уходит в «уход за данными»; addCard для
  ленивого создания.
- Тесты: чистая функция джойна (файлы × карточки → view-модель).

Не трогаем: пайплайн генерации, мост (listGallery остаётся карточным API),
референсы-пул.
