Сайдбар-дерево — фикс ~178px. Поиск папок; «Все карточки», «Без папки»; секция «Избранное» (пины; закреплённая группа остаётся и в дереве); «ПАПКИ» с тулзами: ⋯ вид списка (своя / по имени / по количеству / скрывать пустые / управление папками) и ＋ создать папку верхнего уровня. Дерево: группа — жирное имя, шеврон свёртки (prefs.collapsed), рекурсивный жирный счётчик (свои + все подпапки, union); подпапка — отступ 1 уровень (кап глубины 2). В строках нет кнопок: маркер, имя, статус-★ пина, счётчик. Внизу — подсказка «ПКМ / долгий тап — действия папки».
2
Тулбар: крошки пути «Все карточки › Группа › Папка» (текущая подсвечена, клик — навигация: группа = рекурсивный фильтр), «⋯» меню активной папки (гашено на «Все/Без папки»), поиск референсов (в группе ищет всё поддерево), «＋ В «имя папки»» — назначение новой карточки видно заранее.
3
Сетка карточек 3:4 — repeat(auto-fill, minmax(72px,1fr)), gap 6px, pad 8px, скролл. Имя — 9px по градиенту; точки папок (по одной на каждую папку карточки, ≤ отображаемых, слева снизу); hover/выбор — акцентная рамка. Клик → оверлей.
4
Оверлей-редактор — 260px справа. Head: имя + ✕. Тело скроллится, поля автосохраняются (мигает «Автосохранение»). Закрытие → сетка возвращает ширину.
5
Превью 3:4 → клик открывает лайтбокс на весь экран. Поверх нижнего угла: «Обрезать» / «Заменить картинку» (кроп-диалог).
6
Брейкпоинт — по контейнеру, не по окну: root.clientWidth < 480px (ResizeObserver) → мобильный стек. Сделано из-за боковых панелей ST: 480px контейнера ≈ 768px медиа. UI-зум влияет: плотный масштаб раньше уводит в компакт.

Что видно уже сейчас — нейтральные зацепки для обсуждения, не решения

Оверлей сдвигает сетку. 260px отнимается у области карточек — при узком окне редактор «съедает» ряд превью; альтернатива — наслоение/выдвижение поверх.
Два поиска в разных местах. «Поиск папок» в сайдбаре, «Поиск» карточек в тулбаре — на мобиле их тоже два, на разных экранах.
~178px сайдбар тесен для дерева. Отступ подпапки + длинные имена → обрезка с … (полное имя в тултипе); при 3-м уровне пришлось бы резать агрессивнее — кап глубины 2 это страхует.
Действия папки — только через меню. Кнопок в строках больше нет (чище), но пин/правка требуют ПКМ или долгого тапа — на десктопе без мыши (тач-экран) открывается лист, обнаруживаемость зависит от подсказки внизу сайдбара.
Чип группы в whitelist показывает только прямые карточки. Скоуп при генерации раскрывает поддерево (expandFolderIdsToSubtrees), но в чипе «Генерации» подпапочные карточки не видны — пользователь не может заранее проверить скоуп глазами.
Крошки + свёртка не связаны. Активная подпапка свёрнутой группы остаётся активной; крошки позволяют вернуться, но дерево при этом не разворачивается само.
Карточка-тайл почти без атрибутов. Только картинка, имя и точки папок: описание/алиасы видны лишь в редакторе; имя 9px при мелкой сетке.
Мобильный стек — 4 экрана с общими кусками. Экран группы добавил ещё один рендер; тайлы и тело редактора общие, но список/группа/сетка — три разные разметки одних данных.
Пикер — отдельный мир. Шиты «Переместить/Папки референса» (плоский список с поиском) не показывают дерево — вложенность видна только подписью «в группе …» после поиска.
