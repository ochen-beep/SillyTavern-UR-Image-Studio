# Визуальный перевод расширения под эстетику Фигмы

**Дата:** 2026-07-18
**Тема:** UI/presentation-layer перевод пяти вкладок плавающего окна UR Image Studio под визуальную систему дизайн-макета из Фигмы.
**Подход:** A — CSS-first с дизайн-токенами + полный передел разметки вкладки «Референсы».

## Контекст и мотивация

Существует дизайн-макет из Фигмы (3 скрина + React-референс-код `pasted-text-20260718-193121-5424ae66.txt`), задающий визуальный язык расширения. Текущая реализация (ванильный JS + CSS для SillyTavern) функционально работает, но визуально расходится с макетом. Самый заметный разрыв — вкладка «Референсы»: квадратные карточки 1:1 вместо портретных 3:4, чипы-фильтры переносятся по строкам вместо одной прокручиваемой ленты, избыточный заголовок «Библиотека референсов».

Слой данных (`refs-library.js`: пул, папки, привязка к чату, smart-matching) и логика генерации — рабочие и **не входят в объём** этой задачи.

## Цели

- Привести все пять вкладок к единой визуальной системе дизайн-макета.
- Полный передел вкладки «Референсы» под точную разметку Фигмы.
- Сохранить адаптивность палитры к выбранной ST-теме пользователя (палитра **не хардкодится**).
- Не трогать слой данных и логику генерации/пайплайна/провайдеров.

## Не-цели (явно)

- Не переписываем React → это расширение ST на ванильном JS. React-код из макета — лишь визуальный референс.
- Не пиксель-точное воспроизведение скринов — дизайн-система берётся как ориентир, не как спецификация в пикселях.
- Не меняем поведение модального редактора референса и picker-overlay (только мелкие стилевые правки под токены).
- Не трогаем мобильные правила (bottom-sheet picker,Insets) — сохраняются как есть.
- Не затрагиваем `refs-library.js`, `references.js`, логику провайдеров.

## Дизайн-токены

Новый блок в начале `style.css` (`:root`). Все значения — fallback для ST-переменных, поэтому палитра остаётся адаптивной.

### Поверхности (нейтральный серый, совместим с любым акцентом темы)
| Токен | Fallback | Назначение |
|---|---|---|
| `--uris-bg` | `#1c1c1c` | фон окна |
| `--uris-surface-header` | `#141414` | шапка окна |
| `--uris-surface-tabs` | `#1a1a1a` | полоса вкладок |
| `--uris-surface-card` | `#1e1e1e` | карточки, свёрнутые аккордеоны |
| `--uris-surface-btn` | `#252525` | обычные кнопки, неактивные чипы |
| `--uris-surface-btn-hover` | `#2d2d2d` | hover обычных кнопок |

### Границы
| Токен | Fallback |
|---|---|
| `--uris-border` | `#3a3a3a` |
| `--uris-border-soft` | `#2a2a2a` |
| `--uris-border-accent` | `var(--SmartThemeQuoteColor, #5a9e3a)` |

### Текст
| Токен | Fallback | Назначение |
|---|---|---|
| `--uris-text-strong` | `#d4d4d4` | основной |
| `--uris-text-mut` | `#888` | подписи, метки |
| `--uris-text-dim` | `#666` | подсказки, placeholder |

### Акцент
`--uris-accent` → `var(--SmartThemeQuoteColor, #5a9e3a)`. **Не захардкожен** — в синей/фиолетовой ST-теме подсветка вкладки/чипа идёт в цвет темы.

### Состояния ошибок
`--uris-err: #e05050`, `--uris-err-bg: #1e1010`, `--uris-err-border: #4a2020`.

### Ритм
| Токен | Значение |
|---|---|
| `--uris-radius` | `4px` (карточки, поля, кнопки) |
| `--uris-radius-pill` | `999px` (чипы-фильтры) |
| `--uris-gap` | `6px` |
| `--uris-pad` | `8px` |

## Изменения по файлам

### `style.css` — токены + косметический проход
1. Добавить блок дизайн-токенов (см. выше) в `:root` после существующих `--uris-label-w`/`--uris-tap-min`.
2. В существующих правилах `.uris-window`, `.uris-header`, `.uris-tabs`, `.uris-tab`, `.uris-body`, `.uris-row` заменить хардкод-цвета на токены (fallback-значения те же, поэтому визуально на дефолтной теме без изменений).
3. Мобильный блок (строки ~680–750) оставить без изменений.

### `src/ui/window.js` — остов окна
- Разметка `mountPanel()` остаётся структурно той же (header/tabs/body/resizer).
- CSS-классы уже есть; визуальная плотность регулируется токенами в CSS. JS-изменения не требуются — меняется только CSS.

### `src/ui/tab-references.js` — ПОЛНЫЙ ПЕРЕДЕЛ разметки (главное)
Новая разметка `render(root)`:
- Убрать заголовок `<h4>Библиотека референсов</h4>`.
- **Один скроллящийся ряд чипов-фильтров** (`overflow-x: auto`, класс `uris-refs-filterbar`, скроллбар скрыт).
  - Чипы: «Все», «Без папки», `<имя папки>`…, в конце пилюля **«+ Референс»** в акценте (не отдельная громоздкая кнопка).
  - Кнопка «+ папка» (icon-only) — отдельный элемент справа или иконкой в ряду.
- **Сетка карточек 3:4**: `grid-template-columns: repeat(auto-fill, minmax(72px, 1fr))`, gap `var(--uris-gap)`.
- **Карточка**: `img` во весь тайл (`aspect-ratio: 3/4`, `object-fit: cover`); имя — на полупрозрачной подложке внизу (`linear-gradient` от прозрачного к `rgba(0,0,0,.7)`), `font-size: 9px`, truncate.
- Клик по карточке → `openRefEditor` (без изменений в поведении).
- Слой данных и CRUD — **не трогаются**: вызовы `listRefs/listFolders/createRef/createFolder` те же.
- Picker-overlay (`showPoolPicker`) — мелкие стилевые правки (поверхности под токены), структура и логика мультивыбора сохраняются.

### `src/ui/tab-api.js`, `tab-generate.js`, `tab-gallery.js`, `tab-templates.js` — косметический проход
Только presentation-layer:
- Заменить хардкод-цвета на токены, где они встречаются.
- Унифицировать радиусы/отступы под ритм-токены.
- Подогнать плотность кнопок/полей под визуальную систему Фигмы.
- **Не менять** структуру полей, event-хендлеры, логику accordion-состояний.

## Что НЕ меняется (явно)

- `src/refs-library.js` — пул, папки, привязка к чату, smart-matching, миграции.
- `src/references.js` — upload/compress/dataUrl.
- Логика генерации, `pipeline.js`, провайдеры (`src/providers/*.js`).
- Модальный редактор референса (поведение) и picker-overlay (мультивыбор).
- Мобильные правила (`@media (max-width: 768px)` блоки).
- `manifest.json`, точки входа `index.js`.

## Риски и митигация

| Риск | Митигация |
|---|---|
| Случайно задеть event-хендлеры в референсах | Трогаю только `innerHTML`-разметку; имена классов-хуков (`data-ref-id` и т.д.) сохраняю. |
| Рассинхрон токенов с ST-темой | Все цветовые токены — fallback к `--SmartTheme*`; захардкожены только нейтральные поверхности/границы, совместимые с любым акцентом. |
| Визуальная регрессия на других вкладках | Косметический проход точечный; fallback-значения те же, что сейчас — на дефолтной теме дельта минимальна. |
| Пиксель-точность не достигнута | Заявлено в не-целях: берём систему как ориентир. |

## Проверка

- Визуальная: открыть окно в ST, пройти по 5 вкладкам, сверить с макетом.
- Функциональная: добавить/удалить референс, открыть редактор, сменить папку, мультивыбор в picker — всё должно работать как раньше.
- Мобильная: проверить picker bottom-sheet не сломан.
- Темы: переключить ST-тему с другим акцентом — подсветка должна следовать за темой.
