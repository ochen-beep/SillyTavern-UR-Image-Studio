# Референсы: вложенные папки (2 уровня) + сайдбар без кнопок

**Дата:** 2026-10-04
**Статус:** утверждено пользователем (макеты `docs/design/2026-10-04-refs-sidebar-nesting.html`, `docs/design/2026-10-04-refs-sidebar-minimal-buttons.html` v2)
**Область:** вкладка «Референсы» — сайдбар папок, тулбар, мобильный стек, бело-списочная генерация.

## Проблема

При 40+ папках плоский список сайдбара превращается в простыню: группы сцен/персонажей
не выразить, поиск — единственный быстрый путь. Попутно кнопки ★/✎ в каждой строке
резервируют ~50px ширины и шумят, а часть действий (закрепление) недоступна с телефона.

## Решения (утверждены)

1. **Вложенность глубиной ровно 2**: папка верхнего уровня может содержать подпапки.
   UI не даёт создать подпапку в подпапке (кап в коде: валидация `parentId`).
2. **Тап по папке с подпапками = рекурсивный фильтр** (уникальный union референсов
   поддерева), счётчик группы — рекурсивный. Тап по подпапке — точный фильтр.
3. **Свёртка групп** — device-local prefs (`folderPrefs.collapsed`), переживает перезапуск.
4. **Поиск по папкам уплощает дерево**: совпадения плоским списком с подписью
   «в группе …»; «скрывать пустые» в поиске не действует (как раньше).
5. **Мульти-присвоение `folders[]` не меняется.** Вложенность — слой навигации.
   Референс может лежать в подпапках разных групп.
6. **Удаление папки с подпапками**: confirm с текстом; подпапки поднимаются на
   верхний уровень, референсы не изменяются (кроме самой удаляемой папки —
   её id убирается из референсов, как и сейчас).
7. **Действия папки — без кнопок в строках**: три входа в одно и то же меню —
   ПКМ по строке (десктоп), долгий тап (мобила, `bindCardContextMenu`),
   постоянная кнопка «⋯» в тулбаре, привязанная к активной папке.
   Статус закрепления — маленькая ★ у имени (не кнопка) + секция «Избранное».
8. **Крошки в тулбаре**: «Все карточки › Группа › Папка», клики навигируют.
   «⋯» гаснет (disabled), когда активен виртуальный фильтр (Все/Без папки).
9. **Шапка секции «Папки»: ＋ + ⋯.** ＋ контекстно-умный: активна группа → создаёт
   подпапку внутри; активна подпапка → соседнюю в той же группе; иначе — верхний
   уровень (title отражает назначение). ⋯ — меню вида списка: сортировка (3 пункта
   с галкой), «скрывать пустые», «управление папками».
10. **Создание/перемещение**: подпапка создаётся сразу с `parentId`; перемещение —
    «Переместить в…» через `openFolderSheet` pick-one: цели — группы верхнего уровня
    и «Без группы (верхний уровень)»; недопустимые цели видны приглушённо-disabled.
11. **Генерация**: белый список папок раскрывает группы в поддеревья
    (`expandFolderIdsToSubtrees`) — выбор группы влечёт всех потомков. Старые
    сохранённые folderIds не ломаются (групп раньше не было).
12. **Мобайл**: группы открываются подэкраном стека («группы → внутри группы →
    сетка → карточка»); первая строка экрана группы — «Все из группы».
    Долгий тап по строке папки — то же меню действий (нижний лист).
13. **Drag&drop вложения — не в MVP** (шит с поиском достаточен); добавить отдельно,
    если захочется.

## Изменения по слоям

- `src/refs-library.js`: `normalizeFolder` + `parentId` (null по умолчанию, без
  миграции); `createFolder(name, {parentId})` и `updateFolder(id, {parentId})` с
  валидацией капа глубины и запретом циклов; `deleteFolder` поднимает подпапки;
  хелперы `folderChildrenMap`, `folderDescendantIds`, `folderSubtreeIds`,
  `filterRefsByFolderTree`, `expandFolderIdsToSubtrees`; prefs `collapsed`.
- `src/ui/tab-references.js`: дерево сайдбара (группы/подпапки/свёртка/рекурсивные
  счётчики/поиск-уплощение), контекстные меню строк, шапка ＋/⋯, подсказка жеста,
  тулбар с крошками и «⋯», мобильный экран группы, рекурсивный фильтр активной папки.
- `src/ui/folder-picker.js`: `openFolderSheet` — поддержка disabled-строк (для целей
  перемещения); хелпер порядка дерева (`orderSidebarFolders` остаётся для верхнего уровня).
- `src/pipeline-config.js`: раскрытие folderIds в поддеревья перед выборкой.
- `src/ui/folder-manager.js`: текст подтверждения удаления с учётом подпапок,
  признак родителя в строках списка.
- `style.css`: дерево (отступ, направляющая линия, шеврон), подсказка, крошки,
  контекстная кнопка тулбара, disabled-строки шита; удаление CSS кнопок строк
  (`.uris-folder-pin`, `.uris-folder-edit`).

## Не делаем

- Глубина 3+ (жёсткий кап в валидации, не только в UI).
- Drag&drop, миграции данных, изменения формата экспорта (`parentId` — обычное поле).
- Отдельной сущности «группа»: группой является любая папка верхнего уровня,
  у которой есть подпапки.

## Риски / компромиссы

- ПКМ-жест невидим, пока не выучен — страхуется подсказкой внизу сайдбара,
  постоянным тулбарным «⋯» и уже обученным долгим тапом на карточках.
- Действия над неактивной папкой — 2 шага через тулбар (или 1 жест ПКМ).
- `card-action-menu` выбирает поповер/лист по ширине окна (768px), не контейнера:
  в узком десктопном окне меню покажется нижним листом — осознанно принимается.
- Тулбар плотнее (крошки + ⋯ + поиск + «＋ Референс»): на узком контейнере первыми
  обрезаются крошки, точка перелома ~600px, дальше мобильный стек.

## Тесты

Обновляются контракты DOM сайдбара (кнопки строк удалены), добавляются:
поддерево/рекурсивный фильтр/раскрытие id; валидация parentId (кап, циклы);
lift при удалении; prefs.collapsed; крошки и «⋯» тулбара; меню строки (ПКМ-событие);
мобильный экран группы.
