# UR Image Studio — юзабилити-аудит интерфейса и предложения по улучшению

Дата: 2026-09-15 · Ветка: `feat/inline-engine` · Версия расширения: 0.8.6

Метод: живой осмотр UI на работающем SillyTavern QA (десктоп 1440×900 / 1280×720 и мобильный viewport 390×844), картирование UI-кода (~10 800 строк, включая style.css 2552 строки), сверка с публичными гайдлайнами (NN/g, WCAG 2.2, Material, Apple HIG). Все пути файлов — от корня расширения.

- **Единая система подтверждений**: все деструктивные операции с confirm и текстом последствий; удаление по умолчанию мягкое (storage.js:127-170).

## 2. Найденные баги (быстрые фиксы, P0)

### 2.1 Окно «уплывает» за пределы экрана — главный баг
Воспроизведено: при `scrollY ≠ 0` у документа окно `position:fixed` смещается вместе со страницей. Причина: ST ставит на `<html>` identity-transform (`transform: matrix(1,0,0,1,0,0)`), что превращает html в содержащий блок для fixed-элементов; fixed перестаёт быть viewport-привязанным. Восстановленная геометрия клэмпится только при инициализации (window.js:200-220) и не пересчитывается на scroll/resize окна — при смене вьюпорта шапка с кнопками закрытия уходит за верх, и окно становится невозможно ни перетащить, ни закрыть (Esc не работает — см. 2.2).

Фикс: пересчитывать клэмп геометрии на `scroll`/`resize` (rAF-throttle); при выходе шапки за вьюпорт — авто-возврат окна в видимую зону; хранить геометрию относительно вьюпорта, а не документа.

### 2.2 Главное окно не закрывается клавиатурой
Esc не сверяет `#urisWindow` (обработчиков нет), клика по фону нет (окно немодальное — это норм), единственный выход — клик по «Свернуть». Фикс: Esc при фокусе внутри окна → свернуть; это же спасает от сценария 2.1.

### 2.3 Кнопка «Управление папками» — белая на тёмной теме (мобильные референсы)
`.uris-mobile-manage` (tab-references.js:472) визуально рендерится заливкой `rgb(240,240,240)` — выделяется белым пятном на тёмном тулбаре (подтверждено скриншотом). Причина: кнопка не имеет собственного фона и наследует светлый стиль темы ST. Фикс: явный `background`/`color` для `.uris-mobile-manage` в style.css.

### 2.4 Ресайз окна не работает с touch
Ресайзер слушает только mouse-события (window.js:381-402). На планшете/тач-мониторе окно невозможно растянуть. Фикс: Pointer Events (как уже сделано в FAB и drag-чипах).

### 2.5 Таб-бар без ARIA-ролей
Кнопки вкладок — обычные `button` без `role="tab"`/`aria-selected`, стрелки не переключают вкладки (tabs.js). Фикс: `role="tablist"/"tab"`, `aria-selected`, обработка ←/→ — стандартный паттерн WAI-ARIA Tabs.

### 2.6 Хит-зоны ниже минимума на десктопе
Крестики чипов референсов 18×18 (style.css:1042-1054), иконки шапки окна ~24×24, карандаш 24×24 — ниже минимума WCAG 2.5.8 AA (24×24 CSS px) и сильно ниже рекомендуемых 44–48 px. На мобильных всё сведено к 44 px — хорошо; десктоп тоже должен держать ≥24 px, лучше 32 px.

### 2.7 Разнобой модалок: Esc и фокус-трап
Собственные оверлеи ставят `role="dialog" aria-modal="true"`, но ни один не имеет фокус-трапа (Tab уводит под оверлей), а pool-пикер референсов (tab-references.js:831-916) и batch-upload (ref-batch-upload.js:110-296) не закрываются по Esc. Остальные (folder sheet, folder manager, crop, меню копирования) Esc закрывают. Фикс: общий хелпер `openUrisDialog()` с фокус-трапом, Esc, возвратом фокуса и `lockBodyScroll` (счётчик уже есть, window.js:19-37).

## 3. Предложения по упрощению и интуитивности

### 3.1 Главное окно
- **Esc-сворачивание + «мини-режим»**: между «полное окно» и «скрыто» добавить компакт-полоску (статус + прогресс + ERR-счётчик + кнопка разворота). Сейчас окно 460×560+ закрывает чат, и единственная альтернатива — спрятать всё.
- **Двойной клик по шапке** = свернуть (общепринятый жест), «прилипание» к краям экрана с магнитом.
- **Дефолты масштаба**: у активного пользователя zoom 110% × шрифт 125% — сигнал, что базовые размеры мелковаты. Поднять базовый размер шрифта контролов на десктопе на 1–2 px вместо индивидуальных настроек.

### 3.2 Вкладка «Генерация» (главный сценарий)
Сейчас: промпт + 3 кнопки + **7 дропдаунов подряд** (Стороны/Размер/Quality/Модель/Шаблон/Автоматизация/Флоу) + панель референсов. Проблемы: визуальный шум, непонятна частота использования каждого параметра, на мобильном каждый дропдаун — отдельная строка.

1. **Сгруппировать**: «Стороны + Размер + Quality» → одна строка-сегмент «Формат»; «Модель/Шаблон/Автоматизация/Флоу» → сворачиваемый блок «Параметры» с выбранными значениями в заголовке (прогрессивное раскрытие по NN/g). Частые действия остаются на виду, редкие — не мешают.
2. **Прогресс генерации**: сейчас только текст в шапке и пульс FAB. Генерация длится 10–60 с — по NN/g (>10 с) нужен percent-done индикатор. Минимально: полоса фаз «Шаг 1 → Шаг 2 → Сохранение» + прошедшее время + скелетон-плейсхолдер в галерее/инлайне вместо пустоты.
3. **Мобильный**: кнопка «Сгенерировать» — sticky внизу окна (thumb-zone), а не после 2+ экранов скролла.
4. **Промпт-бокс**: placeholder с коротким примером «что написать»; история последних промптов поста (сейчас черновик один и перезаписывается).
5. Мёртвый хвост: `refreshReferencePanel` биндит несуществующий `details #generate:advanced` (tab-generate.js:1070-1073) — убрать.
6. Term «Quality» (англ.) в ряду русских лейблов — заменить на «Качество».

### 3.3 Галерея
Сейчас: 3 колонки (2 на планшете, **1 на телефоне**), на карточке всегда видны 5 иконок, «Очистить» в шапке, счётчик «4» без подписи.

1. **Мобильный: 2 колонки** вместо 1 — NN/g прямо рекомендует 2-колоночные сетки для изображений на мобильных; 1 колонка при 720 записях — бесконечный скролл.
2. **Карточка = только картинка** (badges поверх), действия — в лайтбоксе (уже мощные) + одна кнопка «⋯» на карточке. 5 всегда видимых иконок × N карточек — главный источник шума.
3. **Массовые операции**: long-press → режим выбора → contextual action bar снизу (N выбрано / Удалить / В референсы / Отмена) + «Выбрать все» + **Undo** (NN/g bulk actions). Сейчас почистить 716 скрытых/потерянных записей (в индексе 720, на экране 4!) нечем.
4. **Счётчик и фильтры**: «4 изображения» + фильтр по чату/персонажу + сортировка; «Очистить» убрать в меню «⋯» (dangerous action вне прямой видимости).
5. **Лайтбокс**: инфо-панель (промпт, модель, источник-пост) по кнопке ⓘ — сейчас метаданные видны только через меню «Копировать». Подписи действий при первом открытии (coach-mark) — 6 безликих иконок.
6. Скелетон-плейсхолдеры сетки на время первой загрузки (NN/g Skeleton Screens 101: скелетоны для полных экранов).

### 3.4 Референсы
Лучшая вкладка по мобильному опыту (стек экранов, превью папок). Мелочи:
- Два поиска на десктопе (папки + карточки) → один поиск с переключателем скоупа или общий поиск + отдельный фильтр папок.
- Имена-числа («1367», «2803») плохо узнаваемы — в batch-upload добавить «Имя из файла» рядом с «Пронумеровать».
- Звёздочка/карандаш папок 24×24 — увеличить hit-area до 32–44 px (padding'ом, не визуалом).
- Исправить белую кнопку (2.3).

### 3.5 API / Настройки / Хранение
- API-вкладка хороша. Добавить заметную «+ Добавить подключение» вверху списка (сейчас поиск конца списка), спиннер на кнопке «Проверить».
- Настройки — один длинный скролл из 6+ секций. NN/g: аккордеоны дают обзор страницы и уменьшают длину скролла — свернуть «Внешний мост», «Уведомления», «Данные и диагностика», «Хранилище» в аккордеоны с summary-строкой; «Интерфейс» и «Поведение» держать открытыми.
- **Хранилище** (сейчас: технические строки «references · 104 зап · 56.4 КБ»): добавить человекочитаемую сводку («N изображений на диске, ~X МБ», метаданные ≠ файлы) и переход к «потерянным/скрытым» карточкам галереи; флаг «ошибка записи» показать и тостом, не только строкой.

### 3.6 Инлайн в чате
- Pending-оболочка: добавить фазу/таймер («Шаг 1/2 · 12 с») — сейчас безликий спиннер; авто-retry уже есть, статус-текст «Ошибка: … — клик: перерисовать» — хорошо.
- Кнопке-камере в `.mes_buttons` — tooltip «Сгенерировать картинку по посту» (сейчас только иконка).

### 3.7 Свод правил модальных окон (применить ко всем)
1. Esc закрывает (кроме кропа с активным выделением — там confirm-поведение уже корректно), фокус-трап + возврат фокуса на триггер (WCAG/NN/g).
2. Мобильные: bottom-sheet (уже есть) + drag-handle и swipe-down-to-dismiss; кнопка закрытия обязательна (жест не должен быть единственным выходом).
3. Confirm: единый компонент — заголовок-вопрос, текст последствий, явная destructive-кнопка красным + «Отмена»; миксовать ST-попапы и свои оверлеи не стоит.
4. Для мягких удалений (карточка галереи) — заменить confirm на toast+Undo: действие обратимо, подтверждение только добавляет трения.
