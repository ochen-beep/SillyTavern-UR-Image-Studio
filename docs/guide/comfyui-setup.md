# Гайд: подключение ComfyUI к UR Image Studio

> Для владельца и пользователей. Уровень: локальный ComfyUI на той же машине, что и SillyTavern (самый частый случай). Дата: 2026-10-01.

Схема работы: URIS берёт workflow (описание графа генерации в API-формате ComfyUI), подставляет в него промпт/сид/модель, отправляет на сервер ComfyUI, дожидается и забирает готовую картинку в галерею. Поэтому настройка — две стороны: **сервер ComfyUI должен пускать браузер SillyTavern**, а **карточка подключения в URIS должна знать адрес и модель**.

## Часть 1. В ComfyUI

### 1.1. Запуск с CORS-флагом

ComfyUI по умолчанию блокирует запросы из браузера с чужим адресом (даже `localhost:8000` → `127.0.0.1:8188` — «чужие» порты). Флаг `--enable-cors-header "*"` это снимает. К любой из типовых установок он добавляется одинаково:

| Установка | Как запустить с флагом |
|---|---|
| **Portable-архив** (`ComfyUI_windows_portable`) | в папке архива: `python_embeded\python.exe main.py --enable-cors-header "*"` |
| **Git + venv** (клон репозитория) | в папке клона: активировать venv → `python main.py --enable-cors-header "*"` |
| **Бандл/свёртка** (Easy-Install и подобные) | как Portable: `python_embeded\python.exe ComfyUI\main.py --enable-cors-header "*"` — bat-файлы бандлов обычно стартуют **без** флага, для URIS они не годятся |
| **ComfyUI Desktop** (приложение с окном) | флаг не пробрасывает в свой бэкенд: закрой десктоп и подними бэкенд вручную способом «Git + venv» из папки установки |

Правила, общие для всех вариантов:

- **Без NVIDIA** (встроенная/AMD-графика) добавь `--cpu` — генерация пойдёт на процессоре: медленно, но работает (SD1.5 512×512 ≈ 2–3 минуты на 8 ядер). С NVIDIA — ничего добавлять не надо.
- **Порт**: по умолчанию 8188; если занят — `--port 8189` и этот же адрес укажешь в URIS.
- Готовый рабочий пример команды для этого стенда (бандл на D:) — `D:\ComfyUI\URIS-TEST-README.md`.

### 1.2. Модели

Чекпойнты кладутся в `ComfyUI\models\checkpoints\` (или путь из `--extra-model-paths-config`). На этой машине уже стоит DreamShaper 8 (SD1.5, 2 ГБ) — оптимально для CPU. Проверка, что сервер жив и модель видна:

```
curl http://127.0.0.1:8188/system_stats
curl http://127.0.0.1:8188/models/checkpoints
```

### 1.3. (Опционально) Свой workflow

Пустое поле workflow в URIS уже даёт рабочие встроенные графы (txt2img, а с референсами — img2img). Свой граф нужен для нестандартных сценариев (Flux, LoRA-стеки, свои сэмплеры):

1. Собери граф в ComfyUI.
2. Получи файл workflow одним из двух способов:
   - **Просто сохрани картинку результата** (правый клик по картинке → Save, или файл из папки `output/`) — URIS сам достанет workflow из метаданных PNG. Dev Mode не нужен.
   - **Workflow → Export (API)** — скачается `.json` (если пункта нет — включи Dev Mode в настройках ComfyUI). Обычный Save не подходит — это UI-формат для редактора, сервер его не исполняет.
3. Замени значения на плейсхолдеры: текст позитивного промпта → `%prompt%`, seed в KSampler → `%seed%`, `ckpt_name` → `%model%`; размер можно зафиксировать числами (`%width%`/`%height%` — если хочешь, чтобы им управляло поле «Стороны»). Удобнее всего это сделать прямо в поле workflow в URIS после загрузки (шаг 4 части 2).
4. Папка готовых workflow на этой машине: `D:\ComfyUI\uris-*.json`.

## Часть 2. В URIS

1. **Перезагрузи SillyTavern** (Ctrl+F5), открой плавающую кнопку → вкладка **API** → добавь подключение.
2. **Адрес**: `http://127.0.0.1:8188`. **Ключ**: оставь пустым.
3. **Расширенные → Протокол**: `ComfyUI (локальный workflow)`. Появится блок workflow и подсказки.
4. **Workflow**: для начала оставь пустым (встроенные графы), нажми «Вставить встроенный txt2img» / «img2img (референс)» или **«Загрузить из файла…»** — принимает `.json` в формате «Export (API)» и PNG, сохранённый ComfyUI (workflow достаётся из метаданных картинки). Под textarea живёт сводка — она на лету показывает, что URIS найдёт в графе: `Промпт ✓ · Seed ✓ · Выход ✓ · LoadImage: 0`. Вставляешь чужой JSON — сводка сразу покажет, чего не хватает.
5. **Жми «Проверить»** → URIS опросит сервер, и в дропдауне «Модель» появятся твои чекпойнты (статус карточки станет зелёным).
6. **Таймаут** (Расширенные): на CPU-машине 300–600 с — стандартных 120 с медленной генерации не хватит.
7. Выбери модель, сделай подключение активным, вкладка **Generate** → промпт → запуск. Референсы прицепляются на вкладке Generate в стрипе «Выбрано для генерации» (режим «Всегда отправлять» на карточке их сам не прицепляет — он лишь определяет политику уже выбранных).

### Доставка

- «Авто» — норм: с CORS-флагом всё идёт напрямую.
- Если флаг поставить нельзя (чужой сервер, не можешь перезапустить) — Расширенные → Доставка = **«Через CORS-прокси ST»** (нужно `enableCorsProxy: true` в config.yaml SillyTavern). Но прокси не переносит multipart → **через прокси референсы работать не будут**.

### Отмена

«Остановить» в URIS гасит ожидание и отправляет ComfyUI `/interrupt`. На новых версиях отменяется твоя задача; на старых — прерывается вся очередь сервера (включая чужие задачи, если они есть).

## Если не работает

| Симптом | Причина | Что делать |
|---|---|---|
| «Failed to fetch», HTTP 403 при «Проверить» | Нет CORS-флага или сервер не перезапущен с ним | Часть 1.1, перезапустить |
| Прямая не работает, но не хочешь флаг | — | Доставка = «Через прокси ST» (без референсов) |
| ST открыт по `https://` или по IP вида `192.168.x.x` | Chrome Private Network Access блокирует доступ к `127.0.0.1` | Открой ST на `http://localhost:8000` |
| «Сервер ComfyUI отвечает, но чекпойнтов не найдено» | Пустая папка models/checkpoints | Часть 1.2 |
| `COMFY_JOB_TIMEOUT` | Медленная машина или чужая задача в очереди ComfyUI | Поднять таймаут; освободить очередь (`http://127.0.0.1:8188` → Queue) |
| `COMFY_PROMPT_REJECTED: … Value not in list` | Модель/значение, которого нет на сервере, или граф с неустановленными кастом-нодами | Выбрать модель из дропдауна (после «Проверить»); убрать/установить кастомные ноды |
| Сводка: «чекпойнт-лоадер без %model%» | В графе лоадер, но нет плейсхолдера | Замени `ckpt_name` на `%model%` или зафиксируй имя вручную |
| «нет метаданных workflow» при загрузке PNG | Картинка не из ComfyUI (пересохранена/сжата сторонним сервисом — метаданные теряются) | Возьми оригинал из папки `output/` ComfyUI или экспортируй `.json` через «Export (API)» |
| Картинки повторяются | В кастомном workflow нет `%seed%` | Замени seed в KSampler на `%seed%` |
| Референс «не применился» | В графе нет ноды LoadImage | Используй img2img-граф (кнопка) или добавь LoadImage |
