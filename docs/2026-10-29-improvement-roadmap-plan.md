# Дорожная карта улучшений: гигиена, перф, данные

Дата: 2026-10-29 · Статус: план (к доизучению) · Источники: живой QA-прогон
2026-10-28 (автоматика), замеры панели на пуле 291 карточка, аудит хранилищ.

---

## 1. Цель

Закрыть подтверждённые дыры автоматизации, снизить главный поток под нагрузкой
больших пулов и добавить утилиты ухода за данными. Пакеты независимы; внутри
пакета — по одному коммиту с тестом.

## 2. Пакет «Гигиена автоматизации» (дёшево, подтверждено тестами)

1. **Гвард Stop-drain.** Живой прогон 2026-10-28 подтвердил: при запаркованном
   payload нажатие глобального Stop отменяет текущий прогон, но слот сразу
   дрейнит припаркованный — новый LLM-вызов стартует вопреки «Stop останавливает
   всё». Фикс: флаг `_stopHold` в events.js — `GENERATION_STOPPED` опускает
   припаркованный payload и ставит флаг; следующий реальный триггер снимает
   флаг (новые события работают, очередь после Stop — нет). Тест: Stop в полёте
   + запаркованный payload → дрейна нет; новое событие после Stop → работает.
2. **Гвард двух вкладок.** `acquireSingletonLock()` возвращает 'busy' — init
   продолжается, и обе вкладки слушают события чата (двойной расход). Фикс:
   при 'busy' не биндить автоматические подписки (остальное — навигатор,
   панель — оставить). Тест: второй контекст → onAutomation не вызывается.
   Дополнение аудита 2026-10-30: при 'busy' также не биндить inline-scanner;
   перечитывать `autoDoneFp` черновика между Stage 1 и Stage 2 (гонка
   `pipeline-stage1.js:262-295`).
3. **Штамп URL на ошибках транспорта.** Сетевые ошибки без адреса
   диагностически глухие («network error» без указания, что стучались в /v1beta
   при отдаче /v1). Приложить endpoint к ошибкам generate/`robustFetch`-аналога
   в image-transport.js; netdump уже знает адрес — синхронизировать форматы.

## 3. Пакет «Перф больших пулов» (замеры уже есть)

4. **Серверные миниатюры референсов при ingest.** Плитки пула декодируют полные
   edge-1024 файлы: замер на 291 карточке — 56–62 мс long tasks на прыжок
   скролла, линейно растут с пулом. `makeThumbnail` (512px webp) уже есть для
   галереи — переиспользовать: при ingest сохранять `thumbPath`, плитки пула и
   пикера читают `thumbPath || imagePath`; lightbox всегда открывает полный
   файл. Старые записи — фолбэк на imagePath, миграция не нужна.
5. **Оптимизация картинок в Worker.** Canvas-декод/энкод инжеста живёт на
   главном потоке: пакетная загрузка крупных картинок джанкает таверну.
   `optimizeReferenceImage` изолирован (декод → ресайз → энкод) и переносится
   в OffscreenCanvas-worker без AbortController-проводки. Запрет Worker из
   старого перф-плана касался пайплайна генерации, не инжеста. Оценить после
   п.4: с миниатюрами инжест остаётся единственным тяжёлым canvas-местом.

## 4. Пакет «Уход за данными» (утилиты)

6. **Свип осиротевших файлов.** Рефкаунтинг уже существует (`releaseRefImage`
   держит файл, пока на него смотрит запись), но UI-инструмента нет: файлы
   удалённых/заменённых карточек оседают в URIS_Refs/URIS_Thumbs. Кнопка
   «Найти ничьи файлы» в Настройках → «Данные и диагностика»: скан обеих папок,
   подсчёт всех ссылок (пул, галерея, гардероб-подобные потребители если
   появятся), превью списком, удаление отмеченных одним подтверждением.
   Серверная часть — список файлов папки уже доступен через user-files.
7. **Экспорт-импорт: сверка целостности** (опционально, после п.6): бэкап
   показывает, сколько файлов осиротеет при удалении записей — подсказка
   перед подтверждением.

## 5. Пакет «Публичность»

8. **README: раздел «Известные ограничения».** Честные границы: ключи
   подключений живут в IndexedDB браузера и не синхронизируются между
   устройствами; Gemini может терять рефы при большом их числе; инлайн-
   автогенерация ограничена политикой конкретного провайдера. Доверие вместо
   маркетинга.
9. **`auto_update: true` в manifest.** Для публичного репо — доставка
   обновлений без переустановки; сейчас false.
10. **EN-документация USER_GUIDE** (опционально, при росте англоязычной
    аудитории; README уже двуязычный в шапке).

## 6. Дорожная карта (крупное, не в этом цикле)

11. **По-свайпные драфты.** Фаза A даёт fp-пропуск, но свайп назад пересоздаёт
    драфт (messageHash) — промпт варианта теряется. Ключи
    `(chatId, msgId, swipeIdx)` + миграция существующих драфтов. Ценность:
    «у каждого варианта свой промпт и своя картинка».
12. **Библиотека образов.** Несколько картинок на одного рефа с частными
    ярлыками («IRL», «AU») и переключением активного образа. Большая фича:
    схема записи, UI выбора, обратная совместимость referenceIds.

## 7. Порядок принятия

**13 (P0) — первым и отдельным коммитом** (деньги); затем 1–3 одним пакетом
«гигиена» (все подтверждены тестами/живым прогоном); 4 — следующий (перф на
готовых цифрах); 14–16 — пакет «аудит-P1»; 6 — утилита; 8–10 — по настроению;
11–12 — дорожная карта. Каждый шаг: `npm test` зелёный, коммит по шву.

## 8. Критерии готовности пакета

- Живой прогон Stop: после нажатия Stop ни одного нового LLM-вызова; новое
  событие после Stop работает.
- Две вкладки: вторая не слушает события генерации.
- Пул 291+: прыжок скролла без long tasks >30 мс (миниатюры).
- Свип на QA-боксе: осиротевшие файлы найдены, удаление не задело живые.

## 9. Пополнение из аудита 2026-10-30

Источник: [2026-10-30-audit-report.md](2026-10-30-audit-report.md) — полный
тест-сьют 1770 ×3 зелёный, P0/P1 спот-чекены повторным чтением кода. Пункты
дописывают существующие пакеты; приоритеты из отчёта.

13. **(P0) Guard дубликатов в «Повторить» ленты очереди.** `resubmitQueueRow`
    (`pipeline-queue.js:362-375`) ставит задачу минуя `findQueuedDuplicate` +
    confirm, которые есть у ручного сабмита — двойной клик или «Повторить» при
    живом авто-повторе = до трёх списаний за картинку. Фикс: общий хелпер
    submitWithDuplicateGuard; помечать строку-оригинал, когда авто-повтор уже
    поставлен. Тест: двойной клик «Повторить» → в очереди одна задача.
14. **(P1) Шардированный стор: манифест не должен называть недоставленный
    шард.** `flushOnUnload` (`sharded-file-store.js:1099-1142`) считает только
    over-limit-скипы; async-отказ keepalive-fetch шарда неотслеживаем, манифест
    уходит → следующая сессия перманентный `readonly`. Фикс: `.catch` + счётчик
    `failed` (подавлять манифест при любом отказе); при `'missing'` с
    `row.count > 0` — recovery-путь `rebuildFromScan()` вместо кирпича.
    Тест: отклонённый shard-fetch при unload → манифест не уходит.
15. **(P1) Редакция ключей на границах выгрузок.** (а) `log/warn/error`
    прогонять через `safeErrorText`-нормализацию перед push в буфер — сейчас
    URL вида `…?key=AIza…` из `gemini.js:66` уезжает в diagnostic-dump открытым
    текстом; (б) `netdump.scrubUrl` — очищать username/password userinfo.
    Тесты: `dumpProblemLog()` без секрета; scrubUrl без `user:pass@`.
16. **(P1) openai-images: 5xx — не доказательство диалекта.** Исключить
    500/502/503/504 из `isDialectCandidate` (`image-openai.js:290-294`):
    после 502 JSON-ноги img2img-нога — второй платный POST при неизвестном
    исходе первой. Тест: 502 → терминальная ошибка, второй ноги нет.
17. **(P2) file-store corrupt-ремонт с сохранением битого текста:** re-read
    ×2, side-файл `<name>.corrupt` перед перезаписью пустым зеркалом
    (`file-store.js:439-453,504-509`) — транзиентная обрезка ответа сейчас
    стирает данные безвозвратно.
18. **(P2) Авто-пайплайн: захват `chatConfig` синхронно в `onAutomation`**
    (`index.js:199-212`) — окно cold `import()` при первой авто-генерации
    снимает конфиг уже после смены чата.
19. **(P2) extraBody-секреты в бэкапе:** расширить `SECRET_KEYS`
    (`image-connection-schema.js:41-48`) — `key`, `secretkey`, суффиксное
    правило `/(^|_)(apikey|secret|token)$/`.
20. **(P2) refs-импорт: канонизация `imagePath`** в `normalizePoolReference`
    (`refs-library.js:239-249`) — сейчас произвольный внешний URL живёт в
    `<img src>` плиток и в `fetch()` при генерации.
21. **(P2) Мост:** `buildPrompt` в `enqueueAutoLane` (как `generate`);
    per-caller allowlist с UI-согласием при первом вызове + мягкий бюджет
    (заготовка — комментарий `bridge.js:22-24`).
22. **(P2) Ручной сабмит vs активные auto/мост генерации того же поста:**
    сверять промпт с `state.activeGenerations` и показывать confirm
    (`pipeline-queue.js:278-283`).
23. **(P3) Пачка гигиены** — 17 пунктов с file:line в отчёте §6; в roadmap не
    дублируется, брать списком при ближайшем чистом прогоне.
24. **(организация) CI + CHANGELOG.** GitHub Actions на `node --test`
    (~8 с на прогон, матрица Node 22/24) — 149 тестовых файлов сегодня
    гоняются только вручную; завести CHANGELOG.md по образцу BB-Comic-Forge.
