# UR Image Studio (beta)

**English summary:** a [SillyTavern](https://docs.sillytavern.app/) extension that turns your chat into images. A text model (Stage 1) distills recent posts into an image prompt, an image model (Stage 2) draws it — or skip Stage 1 and write the prompt yourself. Chat text stays untouched; images land in the extension's gallery with previews inserted into posts. Guide is in Russian: [USER_GUIDE.md](USER_GUIDE.md).

Это расширение для генерации картинок в SillyTavern, в котором текстовая модель может собирать промпт из текущей сцены, контекста чата, лорбуков, карточек {{char}} и {{user}} и отправлять его на генерацию любой text-to-image или image-to-image модели. Промпт можно писать и вручную.

## Что умеет

- Генерировать картинки :)
- Три режима автоматизации: 
	1. Пишешь промпт на генерацию и крепишь референсы самостоятельно 
	2. Генерация промпта по сцене от текстовой модели после ответа от {{char}} с автораспознованием либо ручным прикреплением референсов
	3. Полный пайплан, где после генерации ответа от {{char}} расширение подхватывает сцену, отправляет запрос на генерацию промпта по сцене, подхватывает имена распознанных персонажей, выбирает референсы автоматически и отправляет запрос на генерацию картинки.
- Соблюдать очередь генераций: есть задачи, статусы, отмена, «Повторить». 
- Поддерживает (пока что) 8 источников картинок: OpenAI, Gemini, OpenRouter, шлюзы прокси на NewApi и похожие, Pollinations, Naistera, Cloudflare, локальный ComfyUI.
- Хранить референсы: папки, автоподбор по именам в сцене, массовая загрузка изображений, кроп.
- (альфа, лучше не трогать) Инлайн-картинки прямо в постах: маркеры, кнопка-камера, слова-триггеры.
- Хранить изображения в галерее с папками, избранным и полноэкранным просмотрщиком.
- Хранить настройки на каждый чат отдельно; студия работает и без открытого чата на главной странице.
- Экспорт/импорт без ключей; диагностика без промптов и секретов.

## Установка

1. **Extensions → Manage Extensions** → вставьте
   `https://github.com/ochen-beep/SillyTavern-UR-Image-Studio` → **Install**.
2. Перезагрузите SillyTavern, включите расширение. Дальше — вкладка **API**:
   одно подключение, и кнопка на **Генерации**.

Обновления приходят сами при обновлении SillyTavern (`auto_update`).

## Безопасность

Запросы идут из вашего браузера напрямую или через встроенный прокси ST —
сторонние посредники исключены. Ключи хранятся только в вашем браузере:
не попадают в настройки, бэкапы и дампы диагностики.
Если ST доступен с других устройств — соблюдайте [гигиену сервера](docs/cors-proxy-setup.md) по рекомендациям SillyTavern.

## Известные ограничения

Важно: встроенная уборка Data Maid в SillyTavern 1.19+ считает файлы расширения мусором — [читайте перед чисткой](USER_GUIDE.md).
