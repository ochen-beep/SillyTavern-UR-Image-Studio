# UR Image Studio

**English summary:** a [SillyTavern](https://docs.sillytavern.app/) extension that turns your chat into images. A text model (Stage 1) distills recent posts into an image prompt, an image model (Stage 2) draws it — or skip Stage 1 and write the prompt yourself. Chat text stays untouched; images land in the extension's gallery with previews inserted into posts. The detailed guide is in Russian: [USER_GUIDE.md](USER_GUIDE.md).

Студия генерации картинок для [SillyTavern](https://docs.sillytavern.app/). Текстовая модель (Шаг 1) превращает последние посты в промпт, картинная модель (Шаг 2) рисует по нему — или напишите промпт сами. Текст чата не меняется: картинки складываются в галерею, в посты вставляются превью. Расширение работает со SillyTavern только через публичные API расширений и пользовательских файлов и не содержит кода ST.

## Что умеет

- **Три режима запуска**: ручной промпт, «Строить промпт» (Шаг 1 с правкой результата до оплаты Шага 2) и полный pipeline одной кнопкой; очередь с лентой задач, отменой ожидающих и «Повторить» для упавших.
- **Источники картинок**: OpenAI Images, Gemini (Nano Banana), OpenRouter, chat-completions шлюзы, Pollinations, Naistera, Cloudflare Workers AI (бесплатная дневная квота), локальный ComfyUI — готовые графы или свой workflow из JSON/PNG.
- **Референсы**: пул карточек с папками и автоподбором по упоминаниям в сцене; whitelist на чат, пакетная загрузка, кроп, режим «только описание».
- **Инлайн в чате**: маркеры `[[тип: описание]]`, кнопка-камера и слова-триггеры превращаются в картинки прямо в постах; компакт-режим, повтор при ошибке.
- **Галерея**: хранение в нативной галерее ST, папки, избранное, перегенерация, кроп в референс, полноэкранный просмотрщик.
- **Настройки на каждый чат**: пропорции, размер, качество, модель, шаблон и пресеты; студия на welcome-экране — со своим набором.
- **Окно и уведомления**: плавающее окно с запоминанием позиции, звуки готовности Шага 1/2 — синтезируются в браузере.
- **Данные**: экспорт/импорт бэкапа (без ключей), сетевой дамп и экспорт диагностики — без промптов, ключей и содержимого ответов.
- **Мост для других расширений (эксперимент)**: промпт, генерации, статус и галерея через `globalThis.URIS`.

## Требования

- SillyTavern **1.19.0** — на этой версии расширение разрабатывается и тестируется.
- Источник картинок: любое из поддерживаемых подключений (у каждого свой ключ; ComfyUI локальный и бесплатный). Для Шага 1 — профиль Connection Manager или свой эндпоинт.

## Установка

**Из репозитория** — `https://github.com/ochen-beep/SillyTavern-UR-Image-Studio`:

1. Extensions → Manage Extensions → вставьте адрес в поле установки → **Install**.
2. Перезагрузите SillyTavern и убедитесь, что **UR Image Studio** включён.

**Вручную**: скопируйте `manifest.json`, `index.js`, `style.css`, `src/`, `USER_GUIDE.md` в новую папку под `data/<пользователь>/extensions/`, перезапустите ST и включите расширение.

**Первый запуск**: откройте окно кнопкой-лаунчером → на вкладке **API** добавьте подключение и источник текста → на вкладке **Генерация** нажмите кнопку — результат появится в **Галерее**.

## Безопасность и CORS

- Запросы к сервисам картинок идут из браузера: напрямую, а если эндпоинт не отдаёт CORS-заголовки — через встроенный прокси SillyTavern (`enableCorsProxy: true`). Сторонние прокси не используются никогда.
- Ключи живут только в вашем браузере: не попадают в настройки ST, в бэкапы и в дампы диагностики.
- Если ST доступен с других устройств — потратьте две минуты на гигиену сервера: [docs/cors-proxy-setup.md](docs/cors-proxy-setup.md).
